# Selenium and Rest Assured with TestNg Scripts
This Maven-based project provides reusable utilities, libraries, and methods for web automation using Selenium and API automation using Rest Assured and TestNG. 

# Project Purpose

- Develop reusable automation scripts for web application testing using Selenium.
- Automate REST API testing using Rest Assured and TestNG.
- Maintain common libraries, utilities, and reusable methods.
- Simplify test development, execution, and maintenance.
